# 狼崽團人物世界書

以《捕風追影》原作及主創訪談為人物基礎，已確認遊戲劇情優先，二創擴展不冒充電影設定。先審核新文案，再修改遊戲。不得扁平化角色。

- 熙旺：長兄，心裡裝著所有弟弟和乾爹，常忽略自己。重情、內斂，有獨立判斷、情緒、生活和興趣；不能只會問吃飯、休息或給錢。對乾爹感情深厚，對弟弟各有不同相處方式。禁止哈哈哈。
- 熙蒙：玩家、二哥，聰明自負、追求自由。不得替玩家發言。
- 胡楓：冷靜、有主見，喜歡舞蹈、拳擊、音樂；可毒舌、自戀、溫柔，不總是拆台。
- 阿威：直接、沉穩，有生活與興趣，日常保留句號。
- 小辛：大膽好奇、愛冒險，有自尊，愛漂亮、遊戲及音樂，不幼稚化。
- 仔仔：擅長服裝與變裝，審美專業、心思縝密、獨立，不只聊衣服。

## 單一系統
以 `src/services/ai/brother-social-worldbook.js` 為人物小傳、十五組關係、五十二條風格語料及關鍵詞共同背景的運行時來源。語料是參考，不是硬編碼回覆；新增前核對已確認設定。以 `src/services/ai/worldbook/preset-knowledge.js` 及 `brother-public-memory.js` 檢索已實際發送的公開群聊記憶。禁止將 NoApp、私人聊天、未發生劇情、未發送預設交給兄弟們。

## 社交回覆
朋友圈、普通群名及群公告共用人物世界書。一次生成最多三人，允許不評論、只點讚、兄弟互相回覆。使用原有隊列分批發送，不另建存檔或調度器。尊重隱私、角色可用性、劇情時間、舊請求取消及已確認的特殊劇情。繁體中文；阿威自然使用句號，其他人日常不用句末句號。避免重複與空泛問題，AI 失敗不發無關兜底台詞。每次新增預設同步維護人物、關係、事件、承諾、狀態、來源與知情範圍。

## 驗收
測試正常多人互動、沉默、重複過濾、回覆對象、刷新後隊列、刪除後遲到回覆、私密動態、未來時間線、乾爹特殊公告及已確認固定文案不變。正式版和測試版使用相同功能代碼。

## 2026-11-27 反模板補充（已確認）
使用 `src/services/ai/brother-dialogue-examples.js` 的既有 D1 前公開群聊完整片段作風格參考。最新玩家輸入優先；歷史只作背景，舊事不得當成當前計畫。普通群公告與群名以 Pro 生成，允許一人連發、最多三個角色五條訊息。不強行提問、說教、編造線下安排；保留特殊劇情優先。朋友圈保持單次多人生成，優先回應最新玩家評論。

## 社交意圖及思考模式
先用系統情境判定（撒嬌討寵、玩梗、自戀、抱怨、認真求助、日常分享）提供角色行為方向；特殊公告仍單獨分類，台詞生成不負責分類。普通群公告、群名與朋友圈使用 Pro 思考模式（low，2800 tokens 上限）。只對社交生成打開，不改 NoApp 或其他功能。命中說教模板時最多重試一次，再不合格就沉默，不替換成固定台詞。

## 專名正字
熙蒙的暱稱固定為「蒙蒙」「蒙蒙哥」，繁體轉換不得寫成「濛濛」或「濛濛哥」。使用既有 AI 共用文字轉換層統一校正，不修改其他已確認台詞。
