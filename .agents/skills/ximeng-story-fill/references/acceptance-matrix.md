# 每日剧情填充验收矩阵（不可省略）

每条新增事件链要有 **真实玩家步骤 + 状态检查 + 负面情况 + 旧存档回归**。以下是 D06 报错反推出来的最低要求；按类型勾选不适用并说明原因，而非默默跳过。

| 情景 | 必须验证 | 失败症状 |
| --- | --- | --- |
| **触发** | 主线前置节点未完成时不发送；完成后恰好一次 | D06 没赢比赛就发中奖喜讯 |
| **主动发言** | `me` 只在玩家按 WeChat/NoApp 原生 Send 后写历史 | 付款自动出现熙蒙发言、角色提前感谢 |
| **消息排队** | 多条消息有合理间隔，既不并发弹通知也不滞留多天 | 同一句刷屏、昨日消息不断弹 |
| **主屏/应用一致性** | 从主屏卡片和 App 内进入执行同一个业务 handler | 主屏点心愿直接显示“已完成”，App 内却要付款 |
| **状态分离** | 添加提醒≠购买、付款≠答应、答应≠预约、预约≠完成用餐 | D06 提前宣布订餐成功 |
| **成本** | 一次银行余额校验、一次扣款、相同 ID 的回执不可重复 | 银行余额凭空涨/两次扣350USD |
| **币种** | BTC 估值≠ USD 现金；时间历史报价只用于兑换 | 10 BTC 直接变美元；汇率使用错误日期 |
| **过期** | 过期前与过期后分别测试；已购买不被误判过期 | D06 晚餐 D07 还可补付款 |
| **时钟** | app、主屏、锁屏、短充、跳天、开发者跳日 | 误以为现实时间；跳天重复触发 |
| **迟到与跨日** | 可补历史消息静默发；错过的活动不自动发生 | 没吃饭却收到 D07 “昨天吃太撑” |
| **条件分支** | 不买/买后不发送/买后发送/已订位/过期五态 | D07 无论如何都提聚餐 |
| **订单/实物** | 付款→预期送达日→确认收货→微信照片 | 付款即发“键盘到了” |
| **资产** | 本地路径或 Supabase URL 存在、MIME 正确、图像显示 | 头像404、图片破损、地图卡在0% |
| **刷新续玩** | 合并前旧存档、重启浏览器、重新进入相同聊天 | 已买提醒又回待付款、买两次 |
| **幂等** | 重复点击购买/发信/结算/返回/刷新 | 重复短信/语音/银行交易 |
| **消息通知** | 未读红点、锁屏和顶部通知一致，当前聊天可静默 | 同一个人一句话产生多条重复弹窗 |
| **角色语气** | 是真实生活聊天，不是客服/任务完成报告；熙泰不进群 | 全员说相同口吻、角色错误 |
| **稳定主线** | 新事件仅影响批准的日期/人物，不碰 D01 前历史 | D01私聊或朋友圈消失、D06部署图标丢失 |
| **发布** | 完整测试、资源检查、独立预览、Pages成功、移动浏览 | GitHub CI 通过但线上还是旧版 |

## D06 一次事故的标准回归剧本

1. D06 10:25，已获得 10 BTC 但还未兑换 USD：点聚餐 → 余额不足，不可凭空加钱。
2. 换出足量 BTC → Pacific USD 有真实回执，10 BTC 资产正确减少。
3. 从**主屏**点击“今晚和大家吃饭” → 显示确认购买，**不是已完成**；取消不扣钱。
4. 购买后银行仅扣 USD 350，提醒显示 **已付款 · 去群聊回复**；打开群聊时**没有**任何感谢和订餐句。
5. 熙蒙看到输入框预填“好啊，一起去吃饭！今晚我请客。”。不按 Send 就不会发生后续订位。
6. 按一次 Send：熙蒙 → 小辛/胡枫/阿威感谢 → 熙旺 → 仔仔问想吃什么 → 小辛回答 → 仔仔订餐19:30。每条恰好一次，提醒更新。
7. 19:30 才出现用餐玩笑；20:30 后才出现聚餐图（Supabase JPEG 实际能加载）。
8. D07 如果**没完成熙蒙同意**不提昨晚吃撑；如果已安排晚餐，则才允许后续分支。
9. 开启旧存档：若350已扣过，**不再扣款、不删旧已发消息、不因旧代码再发送一句“付了钱吗”**。
10. 验证非聚餐心愿延迟收货、照片、自然感谢以及正常提醒事项勾选行为没有退化。

## 交付给用户的证据清单

- 审核过的 `day-packet.json` 和明确的剧情文案（不只有 HTML）。
- 修改文件与唯一状态源的说明、运行/业务服务分界。
- 对应测试数、失败数、真实手机模拟截图、未覆盖场景。
- Supabase 路径与 HTTP/MIME 检查（远程）或本地实际包内路径。
- 预览 URL/版本 SHA 与主分支合并 SHA；确认正式 Pages 发布完成。
- 新规则回流到 Skill/审校表；不要只说“都搞定了”。

**不能用“再刷新试试”替代查缓存问题，也不能因为一个 CI 跑过就宣称 iOS 原生交互全部验收。**
