# 熙泰 · 情緒與跨日記憶（第一輪）

## 行為與資料

沿用 `aiDraft.memories`、`aiDraft.xitaiMood` 與既有世界書快照，不新增資料庫、時鐘、消息隊列或第三次模型請求。

- 只有已相認 NoApp 的實際對話可形成自動記憶。既有作者記憶與舊存檔原話保留；一次電話不能淘汰所有舊記憶。
- 熙蒙直接說過的喜好、界線、約定及經歷，保存為帶日期的原話。熙泰明確表達的承諾只在文字已發出或語音已播放完整後記入。原話不等於事實已證實、承諾已兌現。
- 決策模型可選擇新增一條主觀事件，必須提供能從當輪真實發言／實際通話逐字稿核驗的片段。分類：分歧、擔憂、界線、未完之事。主觀原因與客觀原話分欄。
- 釐清須引用已存在 ID 與新原話，檢查原話實際存在且具有相關／修復表達。這是保守的程式校驗，不保證模型的主觀判斷永遠正確。
- 低／中／高的情緒強度每四個遊戲小時淡化一級；使用遊戲現有 03:00 跨日規則，不隨現實後台另開時鐘。平復不會清除未釐清事件。
- 每輪按相關度、未解事件、約定、界線、近期性提取最多 12 條、最多 5 條未解事件，並受 3200 字符序列化預算約束；決策與表達共享該快照。既有作者記憶仍走原作者設定入口。
- 不把 NoApp 私人回憶投放到匿名 MIRAGE 或棋局；未相認、未聽清語音、未執行的草稿／延遲讀取決策不新增主觀回憶。
- 開發者「熙泰世界書」顯示目前情緒、未釐清數量、提取數量；AI / 語音的人設與記憶可審閱實際來源、原話、主觀原因、釐清證據。
