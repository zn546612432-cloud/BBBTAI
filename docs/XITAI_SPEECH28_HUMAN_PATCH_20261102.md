# 陈熙泰自然口语 × MiniMax Speech 2.8 HD（2026-11-02）

> 2026-11-02 修订说明：本文件记录最初 Speech 2.8 适配历史。**最新用户指定的实时声线策略是固定 calm**；以下涉及“自动情绪/强情绪”的文字仅供旧版实验与回顾，不代表当前来电运行逻辑。新行为规则见 [陈熙泰行为世界书 v6](XITAI_BEHAVIOR_WORLDBOOK_V6_20261102.md)。

## 来源与优先级
- 语音来源：用户提供《MiniMax Speech 2.8 HD 中文语音世界书》，by 仓鼠，适用于 speech-2.8-hd。中文句号起句 (breath)、官方 19 项声音事件、0.01–99.99 秒非连续停顿、避免同义拟声重复，已接入 TTS 准备层。
- 聊天行为参考：用户提供《已读不回》。该文档的 seen_no_reply **尚处交互设计阶段**，本分支不假装已实现真实工具调用。
- 本轮作者修改优先：撤销所有自由聊天“禁止短句/每句必须长句”的硬限制，明确禁止过于文艺、格言式、空泛技术隐喻。历史固定剧情逐字保留。

## 音频链路
1. DeepSeek 只负责自然台词和语义 tone，**绝不**向聊天气泡生成标签/舞台说明。
2. `prepareXitaiSpeech` 清理非法标签、转换已知别名、同位置拟声去重，并在第一句及每个中文句号后且确有台词时加入唯一 `(breath)`。顿号、逗号、问号和换行不强制加换气。
3. 除句首换气，附加轻笑/叹气/倒吸气必须有实际文本或 tone 依据，不按照字数配额随机添加。
4. 停顿标签 `<#x#>` 仅用于可发音语句之间；长话可有少量 0.2–0.35 秒思考停顿。电话内不同自然意群之间仍由 `callPause` 控制；**不再为每个中文句号重复插入固定 0.77 秒静音**。
5. 当前正式预览方案：模型 `speech-2.8-hd`、同一人固定 `voice_id`、speed=1.0、pitch=0、**emotion='calm' 固定不变**，不再根据 DeepSeek 的情绪标签自动切换怒吼、惊讶或粗哑声线；Speech 2.8 的其他事件标签仅保留在独立实验与解析层，不能未经作者同意重启。
6. 文字包含英葡单词时启用 `language_boost=auto`，专有名词及人名需真实试听校验。音色 ID 仍沿用项目已配置 ID；**没有用户提供的有效密钥或实测音频，不能宣称最终腔调已达标**。
7. 试听和电话共用 TTS 预处理层。流式合成、特殊语音后期局部拉伸、环境声混音、字幕时间戳、拼音音标字典和音色设计/克隆需分别做功能评审，并非本分支已交付能力。

## 人格重点
- 不强制短句或长句，不将完整复合句当作聪明的证明。
- 不强制每轮 2–5 条或自动扩写短句。
- 不能只有机械的“嗯/好的/知道了”；值得说时具体说，有情绪时可以短、可以拒绝、可以自我修正。
- 禁止诗化感悟、霸总语录、抽象隐喻、每句话都是技术术语，避免 AI 式总结句。
- 保留阶段身份锁，不能提前暴露与三胞胎的亲缘关系。

## 实机验收
1. 在 NoApp 用已有真实 MiniMax Key 和有效 voice_id 试听：自然闲聊、嘲笑对手、认真争执、疲惫挂断、英文或葡语夹杂句。
2. 检查播放过程是否依然卡顿、暂停按钮/重复触发问题；此分支没有修改播放器状态机。
3. 检查字幕无 Sound Tags/JSON，语音没有把标记字面读出。
4. 对照前后两组音频实际听感，再定音色和语速；不同音色的腔调差异可能远大于标签。
5. 不传 API Key 到仓库、聊天记录或可导出存档。GitHub Pages 静态预览需当前会话自行配置有权限的密钥/安全网关。
