# 朋友圈修正版 · 2026-10-29 待验收

基于 BBBTAI/main 的 aac9c87，仅修改朋友圈模块、配图与相应检查。正式 main 等用户预览确认后再合入。

- 头像：去掉对已带 Pages 发布目录的头像地址二次相对解析；保留用户提供的原始头像。
- 赞评：移除常驻赞评文字行；省略号在动态原位展开深灰菜单；支持点赞/取消、原位评论与取消评论，不再点击省略号直接跳到评论页。复用 Lucide 的真实图标。
- 三天可见：个人相册底部只保留一条提示；总朋友圈不逐条或反复显示隐私提示；历史置顶保留。
- 内容：烧麦使用烧麦照、布料使用实物色卡、早安使用白天澳门海滩、晨光使用晨景；下载文俊辉和林秋楠真实自拍；移除不相关的头像复用配图。猫视频封面改成视频实际首帧。来源详见 `public/apps/wechat/media/SOURCES.md`。
- 参考：实际读取 FoundPhone-Studio 的 `WeChatSkin` / `.wx-moment-post`，沿用头像列与内容结构、间距、分隔线、作者颜色；参考项目没有赞评菜单与三天可见的逻辑，这两部分由本项目补齐。MIT 和 Lucide ISC 声明已保留。

验证：198 项现有与新增测试全部通过，Pages 构建通过；逐项验证 7 个角色头像、9 个新增媒体在版本发布路径下只包含一次基准目录且文件存在。浏览器实测正常手机布局及 320px 窄屏，没有横向溢出，图片全部加载；省略号菜单、原位评论发送、个人相册单条隐私提示正常。

离线验收：运行 `node scripts/build-moments-preview.mjs`，生成 `qa/BBBTAI-moments-offline.html`。这个文件直接使用正式朋友圈的渲染器、数据、处理器和样式，照片/视频内嵌，无需联网。顶部可切换人物、日期与时间。它不改动正式存档；只是本轮朋友圈的专项预览，未将其他手机 App 打进文件。
