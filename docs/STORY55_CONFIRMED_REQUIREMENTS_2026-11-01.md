# 《熙蒙的手机》55天版 · 已确认需求与分期开发基线
更新时间：2026-11-01。记录用户已明确选定的要求，不将助手推荐的选项视为决定。

## 产品目标
这是一部从熙蒙视角操作的、可探索的真实手机，而不是一串任务按钮。主线严格可控；玩家在电话、微信、NoApp、MIRAGE、KIRA、GHOST、地图、日记等 App 中自然发现信息、操作、接单与交流。与熙泰的情感关系是中心：主线结局固定，自由交谈影响亲密与表达温度。NPC 不能表现成客服、固定一问一答或永远在线。

## 不可破坏的底线
1. 正式采用 D01–D55 主线；现有较旧文档中的90天规则属于历史版本，不能混入本版日期/死亡状态机。
2. D01 以前始于 2024-03-10 的历史微信记录永远独立保留，测试重置不得删除；开发者已编写的其他剧情和素材也不得被测试覆盖。
3. 固定剧情的玩家回复逐字预置、模拟键入，但每一条都由玩家自己点击发送；不自动发出、不改写、不合并多条。
4. 任何 App 各自保留子目录，但共享统一游戏时钟、事件队列、任务状态、消息通知和路由；不准独立造出不一致的“剧情进度”。
5. 开发者工作台是创作/验证工具，不得把测试操作混进正式玩家存档；不能自动修改剧情来掩盖依赖错误。
6. 未经实际验证不得宣称已发布/已联动。独立分支验证，确认后再合并 main。

## 时间与消息规则
- 固定剧情按脚本时间触发；提前发送预置回复，时钟向脚本时间前进，绝不倒退。
- 正常浏览：现实3秒=游戏1分钟；自由聊天：现实1分钟=游戏2分钟；普通 GHOST：现实3秒=游戏1分钟（脚本例外）。
- 地图移动消耗对应估算的游戏时间；充电、跨夜、55天终点按剧情系统执行。
- 跳过日期/时间后，所有到期的固定消息按原始时间写入对应 App；未读数同步，顶部通知按事件时间依次显示；不强制跳进 App。
- 主线通知可按时到达而不强制打断 GHOST；若玩家点通知主动切 App，正在玩的当前关卡需要重来，前面已完成关卡保留。
- 世界时钟继续走；依赖玩家发送的后续脚本对话等待该操作。玩家连续多条固定消息必须逐条亲自发送。

- 【33 C】跳时补齐原时戳消息、未读及顺序通知。
- 【34 A】GHOST 期间通知正常出现，主动离开则当前关重开。
- 【35 B】主线按时触发，不强制打断正在进行的普通任务。
- 【36 C】独立世界事件照常进行，依赖玩家回复的固定对话等待。
- 【37 A / 38 A】玩家预置话逐条模拟输入、逐条手动发送。
- 【39 C】NPC 回复由开发者设置特定消息/消息组、时间延迟及跨 App 条件。
- 【40 C】聊天气泡编辑器与55天总时间轴共享同一份数据；日期可乱序编写，D01前历史独立。
- 【41 C】导入按稳定事件 ID 智能合并，冲突显示差异，自动备份/撤销，检查跨 App 引用。
- 【42 B】开发者跳 D45，视为 D01–D44 已完成，并重建真实关联状态；不能仅更改日期。
- 【43 C】跳回较早日自动重建那一天的状态，同时保留其他日期的测试快照。
- 【44 C】剧情变更后保留旧快照，提醒版本差异，由开发者选择按旧版恢复或按新版重建，不擅自覆盖。
- 【45 C】保存配置时自动检查关联；还可一键模拟单份任务全链路，并报告错误位置。
- 【46 C】单日测试和全55天自动检查；不自动修改剧情内容。

## MIRAGE → KIRA → GHOST 流程（访谈17–29）
- 【17】未完成的当前关退出后重开，之前已完成关保留。
- 【18 B / 19 A】GHOST 完成不等于已交付；玩家必须进入 KIRA 手动寄出附成果文件的邮件。
- 【20 A】雇主按剧情配置的游戏时间自动验收、付款，不默认追加要求。
- 【21 A】委托本身由开发者编写，按剧情日发布，不随机生成委托。
- 【22 C】每份委托的可接时间、过期、重复领取和可见性可单独设置。
- 【23 C】可同时承接多单，数量上限由开发者配置；每单进度独立。
- 【24 A】超过交付期限后该委托失败，不再允许提交或付款，历史记录保留。
- 【25 A / 26 C】雇佣兵委托是有预置状态演变的世界背景，不派弟弟执行。
- 【27 A / 28 C】MIRAGE 联系人只有固定历史对话，没有自由 AI 聊天；日常上下线时间表可被特殊剧情覆盖。
- 【29】用户明确说这不是重点，未选定细节。
- 钱包、订单、KIRA 邮件、GHOST 成果文件、邮件投递、验收和资金流水必须相互核对且不可重复结算。

## GHOST（访谈47–49）
- 【47 C】主线关卡固定编排；普通委托使用随机小游戏组合，但只随机小游戏，不随机改写剧情或委托本身。
- 五种游戏类型：破译、链接、窃取、隐匿及攻击/验证演出，具体名称与已有代码映射以审查为准。
- 首次部署五关，每关+20%；每关失败或主动离开仅重开当前关。
- 【48 A】不限重试次数；小游戏失败本身不额外扣游戏时间、资金或报酬，亦不进入惩罚分支。普通订单原有交付期限仍生效。
- 【49】尚未回答！不要把助手建议的 C 写成用户要求；开发时先保持可配置参数，不擅自锁定难度曲线。

## 熙泰 / NoApp 核心体验
- AI 与固定剧本必须由一个编排层协调：固定事件不可被模型改写，日常聊天可多气泡、停顿、自己找话题、有限记忆、打断与主动找人。
- 熙泰有作息、忙碌、离线、语音/电话不同表达；不能强制每条都回、不能用机械客服话术。
- 国际象棋链接和 NoApp 彼此打开并保留已发生的棋局记录；离线不能莫名触发在线邀约。
- 电话、语音采用独立的表达及对话节奏要求；机密/服务密钥不得直接写入前端。
