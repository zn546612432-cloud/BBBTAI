# 《熙蒙的手机》剧情内容填充流水线 · v1

这不是另一套游戏引擎。它是**按日填剧情内容的标准流程 + 检查器**，把“要填的内容”和“系统如何执行”分离。适用于 D08–D55 以及已经上线的 D01–D07 修订。

## 快速使用

在拥有 BBBTAI 仓库访问权限的 ChatGPT Work / Codex / 代码助手中说：

> 按仓库里的 `.agents/skills/ximeng-story-fill/SKILL.md` 做 D08。先检查 D01–D07 已有系统，再生成 D08 的事件包、聊天逐条文案、触发和跨日分支。先讨论不写代码；确定后只填现有系统、做隔离预览和完整验收。

**注意**：把文件提交到 GitHub，并不会自动把它安装为所有 ChatGPT 对话的全局技能。其他聊天应引用仓库 Skill 路径；可以导出其文件作为独立技能包。

## 每日 6 张表 → 才开始修改代码

| 内容卡 | 要填什么 | 常见漏项 |
| --- | --- | --- |
| 人物和剧情目标 | 本日普通生活、主线强制、可选事件及人物关系，前一天遗留状态 | 角色进了不该进的群 |
| 触发表 | 游戏日/时间、前置节点、玩家按钮、跨 App 入口、仅一次事件 ID | 付款当成已订好饭 |
| 对话表 | 哪个人、在哪个 App/群、精确台词、相邻消息间隔、玩家须自己发送的台词 | 熙蒙自动说话，NPC 回复来得太快 |
| 状态和资金表 | 当前余额/币种、可购买/已付款/待收货/已收货、过期、D07条件反馈 | 同一心愿在主屏和 App 状态不一样 |
| 图片素材表 | 文件名与用途、Supabase路径、原图、聊天或朋友圈显示位置、URL可达 | 图片没上传却说已经完成 |
| 验收表 | 不买/买后不说话/买后答应/重复点击/跳天/旧存档/离线/手机真实点击 | 单纯运行单测，漏掉真实互动链 |

## 每天需要一份可校验的事件包

1. 复制 `.agents/skills/ximeng-story-fill/templates/day-packet.template.json` 为一个工作分支中的 `docs/story-packets/d08.json`；模板本身不包含 D08 的真实内容，不能偷偷当做剧情发布。
2. 按既有 `story55` 配置确定当天与前置，填写 `events`（含 kind、owner、trigger、actor、thread、timing、requires、delivery、once），资产在 `assets`，验收在 `acceptance`。
3. 命令：`node scripts/validate-story-packet.mjs docs/story-packets/d08.json`
4. 剧情审核通过后把 `stage` 改成 `approved`，再执行 `node scripts/validate-story-packet.mjs --strict docs/story-packets/d08.json`。缺少负面/幂等/旧存档/跨日/资源等测试会报错。
5. **配置包不自动改变游戏**。按已知引擎映射把数据接到现有 `src/story/d08` 或共享服务，运行实际代码与 Playwright/手机点击验证后才叫完成。

示例：`.agents/skills/ximeng-story-fill/examples/d06-dinner.example.json`。它真实记录 D06 的付款→熙蒙亲自发送→大家感谢→仔仔订餐→晚饭照片事件顺序，**只用于审校与测试，不会重复写入游戏聊天**。

## 内容与程序的界线

- **内容属于 Dxx：** 时间、角色、台词、联系人、支线条件、商品/任务参数、照片 ID 和跟进消息。
- **共享服务属于底层：** 时间/电量/充电、消息持久化和红点、原生 Send、提醒事项状态、银行流水、Ghost 关卡运行器、图片解析器、存档恢复与日期同步。
- **仅有跨场景可复用需求才改底层**：比如主屏和提醒事项应该共用同一个购买弹窗。修改前写影响面，修改后跑 D01–目标日前所有回归，不允许给 D08 另写一套弹窗来规避现有 bug。

## 标准交付

开发结束后必须给出：剧情事件摘要、实际台词、改动文件、资源 URL、单测与浏览器测试证据、测试版地址和版本、主分支是否已合并、正式 Pages 是否完成部署、没验过的内容。**不提供只有 HTML 的空演示，不口头声称已合并或已上传图片**。

详细规则在 `.agents/skills/ximeng-story-fill/SKILL.md`，验收矩阵在 `references/acceptance-matrix.md`。每次实际事故应添加一条回归测试并回填技能文档。
