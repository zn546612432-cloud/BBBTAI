# 手机手势、消息显示与键盘适配

## 本次行为

- 桌面左右滑动跟随手指，松开后吸附到相邻页，点分页圆点同样平滑移动。
- 桌面下滑或 App 顶部下拉打开通知中心；上滑或“完成”收起。通知面板支持跟手移动和回弹，覆盖时下层不可误点。
- App 在整个手机区域使用磨砂背景，状态栏与导航统一衔接。聊天仅保留联系人导航，不再额外叠加重复联系人栏。
- 页面切换单独处理过渡。数据变化通过稳定消息 key 更新现有 DOM，保留输入焦点、草稿和滚动位置；只有新消息出现时做小幅淡入。当前聊天不再额外弹出遮挡输入框的重复提示。
- 编辑器可设置今天、昨天、前天或指定日期，以及 HH:mm 发送时间。聊天按照日期变化与五分钟间隔生成居中时间标记。发送日期与“出现条件”相互独立。
- 使用 VisualViewport 的高度、偏移及 resize/scroll 事件调整手机区域；键盘弹出时输入条随可视区域上移，键盘收起后恢复。兼容视口高度也跟随键盘缩小的 WebView。

## 实现位置

`src/system/dom.js`：增量更新；`src/system/gestures.js`：手势分类与拖动；`src/system/viewport.js`：键盘和可视区域；`src/services/messaging/timestamps.js`：消息发送日期与时间标记；`src/styles/motion.css`：手势、全屏磨砂和过渡。

## 验证

27 项 Node 测试通过。浏览器实测左右切页、桌面下拉通知、App 顶部下拉、上滑关闭，以及消息延迟到来时保留输入焦点和草稿，聊天正确展示“昨天 16:04”。键盘尺寸换算通过单元检查；当前环境未提供真实 iPhone 软键盘，未声称完成 iOS 实机验证。
