## 实现范围

1. 聊天直接显示在黑色背景，不使用消息气泡或逐条边框。欢迎语、纯闲聊显示五秒后向上淡出；本次打开期间的完整记录可从右上角查看。任务日志及文件回执保留在当前聊天中。
2. 退出再进入重新显示欢迎语，聊天记录与本轮视觉状态重置。任务状态、研究结果、已生成文件不清除。跨 App 返回及网页重新打开使用同样的会话入口。迟到的 AI 回复不能进入新会话。
3. 每次进入使用大型银白蛇；保留原有骨蛇和苹果绘制，增加呼吸、流动信号、分段金色过渡。金色来自本轮已纳入任务的实际进展，所有任务完成后才完全变金。
4. 外环红点采用与画布相同的方形坐标及 44% 半径；触摸范围为 44px，运行时脉动，完成后仍为红色。
5. 红点详情显示原任务名称、手机时钟计算的运行时间、完成百分比、状态及说明。详情遮罩独立于聊天层，不会清除草稿。
6. 没有新建任务执行器、任务计时器或文件系统。五秒聊天展示沿用 Ghost 的现有刷新节拍，任务继续由原有手机时间与 tickTearAgent 管理。
7. 去掉研究等待阶段按独立视觉时间增加进度的补值。研究初始化后停在现有检查点，直到原有设备验证阶段继续推进；不以等待时间冒充验证完成。
