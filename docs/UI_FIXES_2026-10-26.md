## 后续修复：通知栏玻璃、桌面左右滑动、密码错误反馈

### 1. 下拉通知栏改为透明玻璃
- 原因：`.shade` 的背景是 85% 不透明的深蓝（`#10243ad9`），模糊几乎看不到，整块像实心面板。
- 现在：`src/styles/motion.css` 的 `.shade` 使用白色 7–20% 的渐变 + `backdrop-filter: blur(32px) saturate(1.8)`（含 `-webkit-` 前缀）+ 顶部高光边；通知卡片为半透明白玻璃。壁纸和身后的桌面图标会被模糊后隐约透出。
- 通知栏关闭时 `visibility:hidden`（滑出动画结束后才生效），避免浏览器持续模糊屏幕外的面板。
- `base.css` 里过时的不透明 `.shade` 背景已删除，避免和 `motion.css` 互相矛盾。
- 注意：嵌套的 `backdrop-filter` 只会模糊自己父层内部的内容，所以卡片本身不再加 blur，用半透明白色即可。

### 2. 修复左右滑动
- **邻页漏边（视觉 bug）**：桌面容器内缩了 14px，而每页内边距只有 8px，静止在某一页时下一页的卡片会在屏幕边缘露出约 6px。现在 `.home-pager` 用 `--home-gutter` 负外边距铺满整屏宽度，每页再加回 `gutter + 8px` 的内边距：页面仍然边到边滑动，但静止时相邻页完全在屏幕外。
- **松手判定**：旧逻辑只看拖动超过 45px，快速轻扫不会翻页、慢慢拖一点点反而会翻。新逻辑（`src/system/pager.js`）按「拖动距离 + 松手速度推算的惯性距离」判断，超过页宽约 1/3 翻页；一次手势最多翻一页；最后一页/第一页外有 iOS 式橡皮筋阻尼。
- **抓住动画中的页面不再跳变**：拖动从轨道当前实际位置开始，而不是从目标页位置开始。
- 圆点指示器随手指实时切换，并带宽度过渡动画。
- 手势层 `src/system/gestures.js` 现在记录最近的指针样本并计算 `velocity`；增加 `lostpointercapture` 兜底，浏览器夺走指针时会正常收尾，不会让桌面卡在拖动状态。

### 3. 密码错误改为 iOS 四点晃动 + 震动
- 删除“密码错误，请重试”提示条。第 4 位输错后：四个点保持全满，左右衰减晃动 0.5s，同时触发震动，随后点清空，可以立即重输。
- 震动实现在 `src/system/haptics.js`：Android/Chromium 用 `navigator.vibrate`；iOS Safari 没有该接口，改用 iOS 17.4+ 的 `<input switch>` 轻触反馈（连点 3 次）；都不支持则静默。**iOS 这条路径只做了代码层面的单元测试，没有在真实 iPhone 上验证。**
- 无障碍：错误态加入屏幕阅读器可读的隐藏 `role="alert"` 文本；`prefers-reduced-motion` 下不晃动，改为点闪烁。
- 晃动期间的按键被忽略（`LockScreen.key` 在 `error` 阶段返回 `ignored`），逻辑层未改。

### 验证
- `npm test`：新增 `tests/lock-pager.test.mjs`（9 项）：橡皮筋、拖动偏移、翻页判定（慢拖、轻扫、不跳页、边界）、圆点、速度、震动三条路径、错误态标记，以及两条 CSS 回归护欄（通知栏背景透明度、邻页不漏边）。护欄已确认在旧 CSS 上会失败。
