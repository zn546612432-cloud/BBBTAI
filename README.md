# 熙蒙的手机 · Phone Framework

这是《熙蒙的手机》的**可运行工程骨架**与 UI 预览。正式九十天剧情、真实角色 AI、Supabase 云同步和 MiniMax 语音尚未接入。所有演示文案和模拟回应都标记为 DEMO。

## 本地运行

需要 Node.js 22+：

```bash
npm ci
npm test
npm run build
npm run dev
```

打开 `http://localhost:5173`。正式部署上传 `dist/`，服务器将未知路径回退到根 `index.html`。目前路由在手机内部维护，刷新后从本机数据恢复。

## 已实现

- 根目录只有一个 `index.html`；状态栏、灵动岛、桌面、锁屏、通知中心和返回手势由统一 Shell 管理。
- 25 个 App 各自位于 `src/apps/<app-id>/`，通过 `src/system/registry.js` 注册。桌面从注册表生成；D56 前隐藏 NoApp 与 Instagram。
- `PhoneRouter` 接受 `{appId, route, params}`，保留导航栈与页面位置。通知、邮件、MIRAGE、相册、音乐和棋局都能用同一接口跨 App 跳转。
- `taiPresence()` 是当前唯一的熙泰在线状态来源，结合预览日期与时间。离线和忙碌时主动棋局邀请保持待回应；在线时**本机演示规则**可以延迟回应，绝不冒充真实 AI。
- NoApp 的 DEMO 邀请卡 → 校验邀请 → 国际象棋棋盘 → 合法走子 → 返回原聊天。棋谱、邀请、通知和事件日志写入本机；刷新后仍可继续。同一邀请重复接受不会创建第二场棋局。黑方是基础规则对手，没有真实熙泰棋力。
- 设置 → 开发者模式可修改演示对话与图片、排序消息、更换壁纸和指定图标、调整预览日期及导出 JSON。浏览器数据不自动发布到源码或云端。
- 手机壁纸与两套玻璃图标图集为本项目生成的原创图片；25 款 App 统一映射并裁去图集黑色间隙。MIRAGE 使用独立的深绿内网界面，其余界面遵循统一的冷蓝玻璃视觉。

默认是 D56 的交互演示。若浏览器中存在上一版原型的本机数据，会迁移日期、笔记、照片和部分聊天，所以可能从其他日期打开；可在开发者模式调整。测试锁屏可在设置中操作。

## 目录

| 位置 | 作用 |
| --- | --- |
| `src/system/` | 持续存在的手机 Shell、AppRegistry 与公共界面组件 |
| `src/apps/<id>/` | 每款 App 的独立入口；国际象棋和 NoApp 实现跨 App 邀请 |
| `src/components/` | 共享聊天展示组件 |
| `src/services/` | 状态、路由、深链、Presence、邀请、棋谱、消息及未来服务接口 |
| `src/story/` | 独立剧情内容目录；`demo/` 严格只供界面测试 |
| `src/editor/` | 内容编辑器及以后审核/发布工作流扩展位置 |
| `src/legacy/` | 上一版未发布原型的代码备份，不包含在构建输出中 |
| `public/wallpapers/`、`public/icons/` | 原创图片素材 |
| `supabase/` | 后续接入说明；旧 SQL/代理草案已归档，不能直接部署 |

架构细节和后续接入点见 [ARCHITECTURE.md](ARCHITECTURE.md)。

## 当前限制

- 仅本机浏览器保存；更换设备请先导出备份。图片较多时本机空间可能不足。
- 开发者模式不是权限系统；正式发布必须引入登录、审核记录和服务端权限。
- NoApp 的演示邀请是受标记的剧情 fixture；正式邀请必须在服务端核验发送者、有效期与状态。前端 `senderId` 不可作为可信凭据。
- 通话页没有假接通或假计时。MiniMax API key 只能放在服务端；真实语音与互动通话尚未配置。
- 内网委托仅展示架空界面，不包含现实攻击步骤。

### 锁屏演示

每次重新打开页面都会先显示锁屏。向上滑动或点按底部提示后输入演示密码 `0816`；密码仅用于本地交互原型，不承担真实鉴权。原有聊天和棋局保存在浏览器本地，解锁后继续。

本轮修复、资产位置、验证与交接见 [UI_FIXES_2026-10-26.md](docs/UI_FIXES_2026-10-26.md)。第二页提醒事项表可直接勾选，点击标题进入完整列表，可新增和删除。

聊天编辑器已支持联系人及发言人改名、逐条选择发言人、拖动排序、显示时间和消息出现条件。设置 → 开发者模式 → 对话；完整说明见 [src/editor/README.md](src/editor/README.md)。底栏仅电话与信息，邮件统一为 KIRA。

开发者模式现可在微信、NoApp、MIRAGE、信息中创建新的私聊或群聊窗口。手机公开界面使用年月日与星期；预览页可调整显示日期。真实语音尚未接入，具体接入说明见 [docs/VOICE_INTEGRATION.md](docs/VOICE_INTEGRATION.md)。
