# 聊天内容编辑器

入口：设置 → 开发者模式 → 对话。所有修改保存在当前浏览器，导出 JSON 可留档；不自动发布到正式剧情或云端。

“电话编辑”页管理电话 App 的本机数据：可以修改“熙蒙”的名片和澳门区号、增加／改名／删除联系人、增加／编辑／删除通话记录（包括未接来电）。未提供的真实联系人号码默认为空白，示例通话号码以 `+853` 遮罩显示；编辑结果直接同步到电话 App，并随本机备份一起导出。

短信 App：先点“编辑”→“选择信息”，勾选一条或多条，再点底部红色“删除”并确认；仅删除选中的短信会话，不影响微信等其他聊天记录。

- 修改联系人／群聊标题；展开“编辑发言人名字”修改昵称，角色 ID 保持稳定。
- 每条消息独立选择发言人、编辑正文和气泡显示时间。图片可替换，棋局邀请保持结构化内容。
- 按住卡片左上角 ⠿ 拖动排序，支持鼠标与触摸。也可使用上移、下移或“移到第几条”；支持复制、添加文字／图片、删除。
- 出现条件为：直接保留在记录、到指定游戏日和 HH:mm 弹出、打开当前对话后延迟 0–3600 秒。游戏定时不依赖现实日期。
- 未触发的消息不出现在聊天或列表摘要；到期后写入送达标记。查看其他 App 时生成站内通知，点通知返回对应对话。
- 编辑器打开时暂停消息触发。延迟计时在离开对话、锁屏或切到后台后重置；重返对话再计时。已送达的消息刷新后不会重复弹出。
- “预览弹出”切入当前对话，游戏定时消息同时把本机游戏日／时间调到触发点；NoApp 最早在 D56 测试。已送达消息可以重新等待触发。
- 图片页与预览日期页继续保留。MIRAGE 编辑的联系人可以在内网联系人与聊天页中实际预览。

实现：`conversations/model.js` 管理角色、排序和调度字段；`src/services/messaging/delivery.js` 负责运行时出现和通知，`src/components/chat.js` 统一渲染。旧消息没有 schedule 字段时直接展示，旧存档继续可用。

## 新建窗口与正常日期

在“对话”页最上方展开“＋ 新建对话窗口”，选择微信／NoApp／MIRAGE／信息，再选择私聊或群聊并填写名称。群聊成员每行一位，自动包含熙蒙。创建后选中新窗口，可添加消息、选择发言人、拖动排序和配置触发条件；“预览整段对话”打开对应 App 的实际窗口。NoApp 现在先显示对话列表，可以进入多个窗口。

锁屏、桌面、日历共享剧情日期：第 1 天为 2025-05-19，第 90 天为 2025-08-16；跨午夜推进日期。旧存档首次升级保留内容并迁移日历。预览只编辑剧情天数和时间，公历日期自动计算。桌面显示距离 BIG DAY 的剩余天数。

普通充电直接到次日 08:00、100% 电量。预览页可给重大剧情日配置“完成标记”；剧情规则的 `setsFlag` 写入该标记前，充电显示“充电口进水，稍后再试。”，完成后恢复跳日。未指定的日期不自动杜撰重大剧情。

第 90 天全天禁充；23:59 强制 20% 后冻结所有操作，按游戏时间耗电至第 91 天 03:00 的 1%，随后熄屏。点击黑屏唤醒密码键盘；只有 6180 可以恢复充电，之后使用熙泰密码。期间闹钟、手势、键盘与后台剧情回复不能打断该流程，刷新保留阶段。测试覆盖此状态机与旧存档迁移。

## 发送日期与消息标记

每条消息上方可选择“今天／昨天／前天／指定日期”，并设置发送时间。快捷项会保存为具体日期，所以游戏日期推进后不会把旧消息错误地一直标为今天。聊天里的时间标记按日期变化或五分钟间隔显示，例如“昨天 16:04”和“11:27”。这些显示日期与下方的消息弹出条件分别配置。
