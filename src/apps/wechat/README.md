# 微信一级界面

参考用户提供的 iPhone 微信截图（IMG_4125–IMG_4127），以原生 HTML/CSS 和可缩放 SVG 重建 **微信 / 通讯录 / 发现 / 我** 四个一级标签，不把截图设为整页背景。

- index.js — 微信入口、一级路由、搜索与点击事件；保留共享聊天页和发送/图片附件。
- components/views.js — 四个标签各自的模板、内容渲染及底栏。
- components/icons.js — 独立 SVG 图标（可随时替换，不依赖手机桌面图集）。
- styles.css — 微信专属色彩、行高、分组、字体、按钮、布局。
- public/apps/wechat/ximeng-avatar.svg — 可替换的原创人物头像占位插画；不复制用户私人微信截图的头像与微信号。

说明：一级导航、聊天入口、通讯录搜索、联系人起聊已接通现有状态；朋友圈、扫一扫、设置等二级页面暂时只提供入口提示。所有正式剧情依然从 src/story/ 和编辑器导入，不在 UI 里编造新的 90 天台词。

页面整体按真实微信白色列表、#ededed 背景与 #07c160 绿色选中态实现；顶部状态栏和屏幕底部手势条由手机系统 Shell 统一绘制。
